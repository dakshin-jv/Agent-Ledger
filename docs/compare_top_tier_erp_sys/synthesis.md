# Copy the control language

- Draft ≠ approve ≠ post ≠ pay ([Microsoft](/vendors/microsoft.md) BC Payables; [Intuit](/vendors/intuit.md) bill vs release).
- Chat is engagement; books keep RBAC and audit ([Oracle](/vendors/oracle.md), [SAP](/vendors/sap.md), [Workday](/vendors/workday.md) ASOR, [Sage](/vendors/sage.md) glass box).
- Agent identity and least privilege (Workday ASU; Microsoft agent roles; SAP user-permission inheritance).
- Skill vs agent vs assistant (SAP); Copilot vs agent vs studio (Microsoft); MCP as tools, not a second ledger.
- Timeout = deny (Intuit). Close Workspace as a process hub (Sage) — still map items to one case.

# Do not give away

- One commercial case as the object (lines, money, owner, evidence).
- Named owner accepts or returns the current version.
- Funding as a second gate after commercial accept.
- Six workspaces as views of that case.
- Isolated per-case run; withdraw / undo / reverse as product law.
- Goods P2P as the first journey. [Infor](/vendors/infor.md) already owns product-centric **modules**. Sage X3 procurement Copilot is incoming — that window can close.

# Novelty claim that still holds

“AI in ERP” is table stakes. The remaining claim is a **case-first goods-commerce ledger**: intent → draft → named owner on a version → funding gate → recover, with workspaces as views. Do not claim novelty on copilots, invoice OCR, or “agents inherit user permissions.”
