# Purpose

Record how the world’s largest ERP vendors (by 2025 application revenue) use AI and agents, and whether that matches AgentLedger: intent first, one commercial case, named owner of a version, funding as a second gate, ledger as system of record, workspaces as views, isolated case runs, recovery.

This is a **research bundle**, not an implemented product and not a claim that AgentLedger is unique in every slogan. “AI in ERP” is table stakes. The remaining claim is the **case-first goods-commerce ledger**.

# Start here

1. Read [AgentLedger criteria](/foundation/agentledger-criteria.md) and [ranking](/foundation/ranking.md).
2. Read [synthesis](/synthesis.md).
3. Open a vendor file only when that company is in scope.
4. Treat GA vs early-access vs press as labelled in each file. Do not treat marketing “execute” as production.

# Authority

- Explicit AgentLedger design in `AGENTS.md` and `plan/ERP_Design_OKF_Bundle/` is the scorecard.
- Vendor files are **inferences from public docs, help, and press** (10 October 2026), not live-tenant audits.
- ARTW rank ≠ goods-commerce peer. CSI, FIS, and Roper rank on vertical/core-banking roll-ups.
